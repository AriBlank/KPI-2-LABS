# ADR-01 Використання Mermaid для створення ER-моделі

**Статус:** прийнятий

## Контекст

Для ER-моделі потрібен декларативний синтаксис, який є простішим та може бути відображений в GitHub

## Рішення

Вибрано Mermaid для даної задачі.

## Альтернативи
- PlantUML: підходить для важких діаграм, але має важкий синтаксис та не підтримується GitHub

## Наслідки
+ GitHub відображає діаграму автоматично з .mmd файлів
+ Завдяки простому синтаксису витрачено менше часу
- Немає детальнішої моделі, нотацій
