# онлайн-магазин
сервіс, цілью якого є продаж техніки від різних брендів під однією компанією

# користувачі
покупець - оформлює та оплачує замовлення

# об'єкти
у системі зберігаються бренди, товари, покупці, замовлення та їхні позиції, платежі

# процеси
покупець обирає товар(и) і оформлює замовлення. замовлення може бути оплачене декількома частинами 

# вибір домену 
вибрано бо він має декілька типів зв'язків, наприклад: 1:N покупець-замовлення, замовлення-оплата, бренд-товар; M:N замовлення-товар через асоціативну сутність із власними атрибутами, наприклад кількість та ціна товару
